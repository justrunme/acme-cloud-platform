# Security Policy

## Supported Versions

Only the latest released version of this project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately through [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository.

Do not open public issues for security reports.

To submit a private report:

1. Open the repository on GitHub.
2. Go to **Security** → **Advisories** → **Report a vulnerability**.
3. Include a clear description, impact assessment, and reproduction steps if available.

You should receive an acknowledgment after the report is reviewed. If the vulnerability is confirmed, a fix will be prepared and coordinated through the advisory before any public disclosure.
